# 템플릿 작성 규칙

모든 챕터(`chapters/weekN/chXX_*.md`)는 [chapter_template.md](chapter_template.md)를 복사해 작성합니다.

## 1. 파일 명명 규칙

| 규칙 | 예시 |
|---|---|
| `ch` + 두 자리 번호 + `_` + 영문 소문자 키워드 | `ch04_safeguard_tech.md` |
| 번호는 코스 전체 통번호 (주차별로 다시 시작하지 않음) | week2 첫 챕터 = `ch07_...` |
| 주차 폴더에 저장 | `chapters/week2/ch07_governance_overview.md` |

## 2. 필수 섹션 (순서 고정, 삭제 금지)

| # | 섹션 | 필수 여부 | 비고 |
|---|---|---|---|
| 0 | 메타정보 표 | 필수 | 법령 확인일 반드시 기재 |
| 1 | 학습 목표 | 필수 | 3개 이내 |
| 2 | 한 줄 비유 | 필수 | **정확히 1줄** |
| 3 | 법령 조문 | 필수 | 조·항·호까지, 원문 인용 + 쉬운 풀이 |
| 4 | 실무 적용 (관리적·기술적·물리적) | 필수 | 해당 없는 영역은 "해당 없음 + 사유" 기재 |
| 5 | 프로세스 다이어그램 (Mermaid) | 필수 | 아래 3장 규칙 준수 |
| 6 | 위반·처분 사례 | 필수 | 의결 연도·처분 유형·위반 조문 명시 |
| 7 | 오답노트 | 필수 | 최소 3개 |
| 8 | 고객사 점검용 체크리스트 / 산출물 연계 팁 | 필수 | 최소 하나 |
| 9 | 퀴즈 | 필수 | 3~5문항, 정답은 본문에 쓰지 않음 |
| 10 | 참고 자료 | 필수 | 공식 출처 URL |

## 3. Mermaid 작성 규칙 (엄격)

- 모든 노드 텍스트·엣지 라벨은 **반드시 쌍따옴표(`" "`)로 감쌉니다.**
- `_`, `()`, `[]`, `/`, `·` 등 특수문자 포함 시 예외 없음.
- 색상은 `classDef`로만 지정하며, 허용 HEX 4종만 사용합니다.

```text
✅ Good : A["user_id 확인"] -->|"권한 검토"| B["안전성_확보조치_점검"]
❌ Bad  : A[user_id 확인] -->|권한 검토| B[안전성_확보조치_점검]
```

표준 classDef (복사해서 사용):

```text
classDef gray   fill:#808080,stroke:#808080
classDef red    fill:#c35b5b,stroke:#c35b5b
classDef green  fill:#3cb371,stroke:#3cb371
classDef yellow fill:#daa520,stroke:#daa520
```

## 4. 스타일 규칙

- **폰트 색상 지정 금지** (`color:` 속성, `<font color>` 사용 금지) → 다크/라이트 모드 자동 대응
- 강조 배경색은 `#808080`, `#c35b5b`, `#3cb371`, `#daa520` 만 허용
  - Markdown 본문에서는 렌더러별로 HTML `style`이 제거될 수 있으므로, 본문 강조는 **이모지 라벨 + 표**를 기본으로 사용하고 배경색은 Mermaid `classDef`에서 적용합니다.

| 라벨 | 대응 색 | 의미 |
|---|---|---|
| 🟥 필수/위반 | `#c35b5b` | 법정 의무, 처분 사례 |
| 🟨 주의 | `#daa520` | 오답노트, 해석 주의 |
| 🟩 양호 | `#3cb371` | 적합 판정, 모범 사례 |
| ⬜ 참고 | `#808080` | 배경·구법 비교 |

## 5. 법령 인용 규칙 (할루시네이션 방지)

1. 조문은 **국가법령정보센터 현행 법령 원문**에서 복사하여 인용합니다. 기억에 의존해 쓰지 않습니다.
2. 인용 형식: `「개인정보 보호법」 제29조(안전조치의무)` / `「개인정보의 안전성 확보조치 기준」 제8조제1항`
3. 시행령·고시 조문 번호는 개정으로 자주 바뀌므로 **메타정보의 `법령 확인일`** 과 함께 기록합니다.
4. 처분 사례는 **개인정보보호위원회 공개 의결서**에 근거하며, 확인되지 않은 금액·기업명은 쓰지 않습니다. 불확실하면 `[확인 필요]` 표기.
5. 수치 기준(보관 기간, 대상 규모 등)은 반드시 출처 조문을 괄호로 병기합니다.

## 6. 작성 완료 셀프 체크

- [ ] 한 줄 비유가 정확히 1줄인가?
- [ ] 모든 조문 번호를 법령 원문과 대조했는가?
- [ ] 관리적·기술적·물리적 3영역을 모두 다뤘는가?
- [ ] Mermaid 노드·라벨이 전부 쌍따옴표로 감싸져 있는가?
- [ ] 오답노트 3개 이상, 체크리스트 또는 산출물 팁이 있는가?
- [ ] 퀴즈 정답을 `answers_and_explanations.md`에 등록했는가?
- [ ] 폰트 색상 지정이 없는가?
